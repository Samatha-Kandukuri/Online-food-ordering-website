# Foodie Hub 🍔🍕

A simple online food ordering frontend web application built using HTML, CSS, and JavaScript.

## Features
- Display food menu items
- Add items to cart
- Remove items from cart
- Dynamic cart update
- Clean and responsive UI

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Type
Frontend Developer Mini Project
